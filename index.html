ENGINES
E-01 FLOATCHECK

Parses a P6 (.xer) export, runs a forward and backward pass to get total float for every activity, then layers the DCMA 14-point health check and a greedy least-cost crashing model on top.

COMPUTES
  • 01  XER parsing (activities, relationships, WBS, calendars)
  • 02  CPM forward & backward pass, total float
  • 03  DCMA 14-point schedule health check
  • 04  greedy least-cost crashing
OPEN FLOATCHECK  →
E-02 LEADTIME

Takes the same CPM output and works backward from each material's lead time to an order-by date, then ranks every match against how much float it actually has.

COMPUTES
  • 01  keyword match to a long-lead material library
  • 02  backward pass from lead time to order-by date
  • 03  ranking by days remaining, tied against total float
OPEN LEADTIME  →

Both engines share one CPM implementation (/lib/xer-parser.js, /lib/cpm-engine.js, /lib/float.js) — the same forward/backward pass and the same float, not two separate calculations that could quietly disagree.
